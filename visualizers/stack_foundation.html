Stack Foundation

Understand the core behavior of a stack as a Last-In First-Out structure, with push and pop operations driving the visual flow.

Theory

A stack is one of the most fundamental data structures in computer science. It follows the Last-In-First-Out (LIFO) principle, where the last element added is the first one to be removed. Imagine a stack of plates in a cafeteria—you add new plates to the top and remove them from the top. This simple concept is incredibly powerful and appears everywhere in programming, from managing function calls to implementing undo features.

  • LIFO Principle: Last In, First Out - the most recently added element is the first to be removed
  • Operations: Push (add to top), Pop (remove from top), Peek (view top without removing)
  • Real-world Applications:
    • Function call stack in programming languages
    • Undo/Redo functionality in text editors
    • Browser back button history
    • Expression evaluation and syntax parsing

Problem Statement

A stack stores elements in a vertical order where the most recently added item is removed first. Use the visualizer to push new values onto the stack and pop them in LIFO order.

4typedef struct Stack {
5int *arr;

10Stack* createStack(int capacity) {
11Stack* stack = (Stack*)malloc(sizeof(Stack));
12stack->capacity = capacity;
13stack->top = -1;
14stack->arr = (int*)malloc(stack->capacity * sizeof(int));
15return stack;
16}
17
18int isFull(Stack* stack) {
19return stack->top == stack->capacity - 1;
20}
21
22int isEmpty(Stack* stack) {
23return stack->top == -1;
24}
25
26void push(Stack* stack, int item) {
27if (isFull(stack)) {
28printf("Stack overflow\n");
29return;
30}
31stack->arr[++stack->top] = item;
32printf("%d pushed to stack\n", item);
33}
34
35int pop(Stack* stack) {
36if (isEmpty(stack)) {
37printf("Stack underflow\n");
38return -1;
39}
40return stack->arr[stack->top--];
41}
42
43int peek(Stack* stack) {
44if (isEmpty(stack))
45return -1;
46return stack->arr[stack->top];
47}
48

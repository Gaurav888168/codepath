## ❓ Interview FAQs & Solutions

### 1. How do I solve the Two Sum LeetCode problem?

The Two Sum problem (LeetCode 1) requires finding two numbers in an array that sum to a target. The optimal solution uses a hash map to store values and their indices, achieving O(n) time complexity. Kodin provides interactive visualization to understand this algorithm step-by-step.

### 2. What is the best approach for Valid Parentheses problem?

Valid Parentheses (LeetCode 20) is best solved using a stack data structure. Push opening brackets and pop when encountering closing brackets. This approach ensures O(n) time and O(n) space complexity. Learn with Kodin's interactive visualizations.

### 3. How to reverse a linked list efficiently?

Reverse Linked List (LeetCode 206) can be solved iteratively using three pointers (prev, current, next) in O(n) time with O(1) space complexity. Kodin visualizes each step to help you understand the pointer manipulation.

### 4. What is the most efficient solution for Merge K Sorted Lists?

Merge K Sorted Lists (LeetCode 23) can be solved using a min-heap or priority queue approach with O(nk log k) time complexity, where n is the average list length and k is the number of lists. Kodin provides step-by-step visualization.

### 5. How to find the Kth Largest Element in a stream?

Kth Largest Element (LeetCode 215) is efficiently solved using a min-heap of size k. Each new element takes O(log k) to process. Kodin visualizes this technique for better understanding.

### 6. What is the 0/1 Knapsack problem and how to solve it?

The 0/1 Knapsack problem (LeetCode 416) is a classic dynamic programming problem. You cannot take partial items. Build a 2D DP table where dp[i][w] represents the maximum value using first i items with weight w. Time: O(nW), Space: O(nW).

### 7. How does Dijkstra's algorithm find shortest paths?

Dijkstra's Algorithm (LeetCode 743) uses a min-heap to greedily select the closest unvisited node. Update distances to neighbors and repeat until all nodes are visited. Time: O((V+E) log V). Perfect for weighted, positive-edge graphs.

### 8. What is the difference between BFS and DFS?

BFS (Breadth-First Search) explores nodes level by level using a queue, finding shortest paths. DFS (Depth-First Search) explores as far as possible using a stack or recursion, useful for topological sorting. Both are O(V+E) time complexity.

### 9. How to find the Longest Substring Without Repeating Characters?

Longest Substring Without Repeating Characters (LeetCode 3) uses a sliding window with a hash map. Maintain two pointers and expand/contract the window based on character frequency. Time: O(n), Space: O(min(n, charset)).

### 10. What is the Container With Most Water problem?

Container With Most Water (LeetCode 11) uses the two-pointer technique. Start from both ends and move the pointer pointing to smaller height inward. This greedy approach finds the maximum area in O(n) time.

### 11. How to find Top K Frequent Elements?

Top K Frequent Elements (LeetCode 347) uses a min-heap of size k. Count frequencies with a hash map, then keep k largest elements in heap. Time: O(n log k), Space: O(n).

### 12. What is Dynamic Programming and why is it important?

Dynamic Programming is an optimization technique that solves overlapping subproblems by storing results. It breaks problems into smaller subproblems and combines solutions. Essential for problems like Fibonacci, Knapsack, and Longest Common Subsequence.

### 13. How does Binary Tree traversal work?

Binary Tree traversal has three methods: Inorder (Left-Root-Right), Preorder (Root-Left-Right), and Postorder (Left-Right-Root). Each has O(n) time complexity. Kodin visualizes each traversal technique step-by-step.

### 14. What data structures are essential for coding interviews?

Essential data structures include Arrays, Linked Lists, Stacks, Queues, Hash Tables, Trees (Binary, BST), Heaps, and Graphs. Master these fundamentals to solve 80% of LeetCode problems. Kodin provides interactive visualizations for all.

## 🛠️ Step-by-Step Problem Tutorials

### 💡 How to solve Two Sum LeetCode Problem 1

*Learn the optimal hash map approach for Two Sum problem*

* **Step 1: Create a hash map to store values** — Initialize an empty hash map to store number-index pairs
* **Step 2: Iterate through the array** — For each number, check if complement (target - num) exists in hash map
* **Step 3: Return indices** — If complement found, return both indices; otherwise add current number to map

### 💡 How to solve Valid Parentheses LeetCode Problem 20

*Use stack to validate balanced brackets*

* **Step 1: Initialize a stack** — Create empty stack to track opening brackets
* **Step 2: Process each character** — Push opening bracket, pop and match closing bracket
* **Step 3: Validate result** — Stack must be empty for valid sequence

### 💡 How to solve Reverse Linked List LeetCode Problem 206

*Iterative approach using three pointers*

* **Step 1: Initialize pointers** — Set prev=null, current=head, next=null
* **Step 2: Traverse and reverse** — Store next node, reverse current link, move pointers forward
* **Step 3: Return new head** — Previous pointer becomes the new head

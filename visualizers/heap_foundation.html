Heap Foundation

Understand binary heaps with Min Heap and Max Heap structures, and master insertion, deletion operations with complete C implementation.

Theory

A Heap is a specialized tree-based data structure that satisfies the heap property. It's a complete binary tree where every parent node is either greater than (max heap) or less than (min heap) its children. Heaps are used in priority queues, sorting algorithms (heap sort), and many optimization problems.

  • Complete Binary Tree: All levels filled except possibly the last, which is filled left to right
  • Min Heap Property: Parent ≤ Children (smallest element at root)
  • Max Heap Property: Parent ≥ Children (largest element at root)
  • Key Operations:
    • Insert: Add element at end, bubble up O(log n)
    • Delete/Extract: Remove root, replace with last element, bubble down O(log n)
    • Peek: View root element O(1)
    • Heapify: Build heap from array O(n)
  • Real-world Applications:
    • Priority Queue implementation
    • Heap Sort algorithm
    • Dijkstra's shortest path algorithm
    • Top K elements in a stream
    • Huffman coding for compression

Problem Statement

A heap stores elements in a complete binary tree where the heap property is maintained. For a Min Heap, each parent is smaller than its children. Use the visualizer to insert values and see how the heap structure is maintained.

5typedef struct MinHeap {
6int *arr;
7int size;
8int capacity;

11MinHeap* createMinHeap(int capacity) {
12MinHeap* heap = (MinHeap*)malloc(sizeof(MinHeap));
13heap->capacity = capacity;
14heap->size = 0;
15heap->arr = (int*)malloc(capacity * sizeof(int));
16return heap;
17}
18
19int parent(int i) { return (i - 1) / 2; }
20int left(int i) { return 2 * i + 1; }
21int right(int i) { return 2 * i + 2; }
22
23void swap(int *a, int *b) {
24int temp = *a;
25*a = *b;
26*b = temp;
27}

29void bubbleUp(MinHeap* heap, int index) {
30while (index > 0 && heap->arr[parent(index)] > heap->arr[index]) {
31swap(&heap->arr[parent(index)], &heap->arr[index]);
32index = parent(index);
33}
34}
35
36void bubbleDown(MinHeap* heap, int index) {
37int smallest = index;
38int l = left(index);
39int r = right(index);
40
41if (l < heap->size && heap->arr[l] < heap->arr[smallest])
42smallest = l;
43if (r < heap->size && heap->arr[r] < heap->arr[smallest])
44smallest = r;
45
46if (smallest != index) {
47swap(&heap->arr[index], &heap->arr[smallest]);
48bubbleDown(heap, smallest);
49}
50}

52void insert(MinHeap* heap, int value) {
53if (heap->size == heap->capacity) {
54printf("Heap is full\n");
55return;
56}
57heap->arr[heap->size] = value;
58bubbleUp(heap, heap->size);
59heap->size++;

61}

63int extractMin(MinHeap* heap) {
64if (heap->size == 0) {
65printf("Heap is empty\n");
66return -1;
67}
68int root = heap->arr[0];
69heap->arr[0] = heap->arr[heap->size - 1];
70heap->size--;
71bubbleDown(heap, 0);
72return root;
73}

75int getMin(MinHeap* heap) {

77return heap->arr[0];

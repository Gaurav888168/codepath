Maximum Subarray Sum Visualizer

Understand Kadane's algorithm step by step: at each index, decide whether to extend the current subarray or start fresh from current element.

Theory

Kadane's algorithm solves maximum subarray in O(n). Keep running sum currentSum and best answer maxSum. If extending hurts, restart from current element.

  • Transition: currentSum = max(arr[i], currentSum + arr[i])
  • Best update: maxSum = max(maxSum, currentSum)
  • Complexity: Time O(n), Space O(1)

Problem Statement

Given integer array nums, find contiguous subarray with largest sum and return the sum.

Example: nums = [-2,1,-3,4,-1,2,1,-5,4] => 6 from subarray [4,-1,2,1].

Approach

How It Works

Start from left to right and keep two key variables in mind:
1) Current running subarray (best subarray ending at current index).
2) Best answer so far (largest sum seen anywhere).
At each number, ask:
• Should I continue extending?
• Or should I restart fresh from here?

If the previous running sum is negative/hurting the total, drop it completely and restart from the current number. Then check if this new sum is the best we've seen globally.
Why it works: Single pass through array, O(n) time, O(1) space. Greedy approach finds optimal answer without backtracking.

Understanding the Algorithm

Line 2-3: Initialize both current and best with the first element

Line 5: KEY DECISION — At each element, ask: "Should I extend the current subarray or restart fresh?" If nums[i] is better than current+nums[i], restart from here.

Line 6: After deciding on current, check if it's the best we've seen globally.

Result: One pass through the array, tracking best subarray ending at each position and overall best.

Theory & Concepts

What is Tree Traversal?

Tree traversal is the process of visiting all nodes in a tree data structure in a specific order. Each traversal method defines a unique visiting sequence, making them suitable for different problems. The choice of traversal depends on your use case: some problems require processing parent before children (preorder), some require processing left subtree first (inorder), and some require processing children before parent (postorder).

Three Kinds of Tree Traversal

Preorder (NLR)

Visit → Left → Right
  • Process node first, then recursively traverse left subtree
  • Finally, recursively traverse right subtree
  • Order: Parent visited before children
Example: A→B→D→E→C→F→G

Use cases: Create tree copy, print tree structure, prefix notation

Inorder (LNR)

Left → Visit → Right
  • Recursively traverse left subtree first
  • Process node in the middle
  • Finally, recursively traverse right subtree
Example: D→B→E→A→F→C→G

Use cases: BST in-order = sorted, infix notation

Postorder (LRN)

Left → Right → Visit
  • Recursively traverse left subtree first
  • Then recursively traverse right subtree
  • Process node last, after both children
Example: D→E→B→F→G→C→A

Use cases: Delete tree, postfix notation, find height

Approach In Plain English

Step 1: Choose Traversal Rule

Pick the exact visit order for one node: preorder = Root-Left-Right, inorder = Left-Root-Right, postorder = Left-Right-Root.

Step 2: Recurse on Subtrees

At each node, recursion solves the left and right subtree using the same rule. Base case: null child returns immediately.

Step 3: Build Final Sequence

Whenever a node is visited as per rule, append it to output. Final list is the traversal result shown in the right panel.

Complexity

Time Complexity

Each traversal visits every node exactly once, so time complexity is O(n).

Space Complexity

Recursive stack takes O(h), where h is tree height. Worst case (skewed tree): O(n).

Creating & Connecting Tree Nodes

Step 1: Define Node Structure
Each node must store data and pointers/references to its left and right children. This creates the basic building block of the tree.

Step 2: Create Nodes
Allocate memory for each node and initialize it with data. Set left and right children to null initially.

Step 3: Connect Nodes
Link parent node's left/right pointers to child nodes. For example: root.left = nodeB; root.right = nodeC. This establishes parent-child relationships and builds the tree structure.

Tree Structure & Traversals

// Node Structure
struct Node {
    char data;
    struct Node* left;
    struct Node* right;
};

// Create a new node
struct Node* createNode(char val) {
    struct Node* node = 
        (struct Node*) malloc(sizeof(struct Node));
    node->data = val;
    node->left = NULL;
    node->right = NULL;
    return node;
}

// Preorder: Root → Left → Right
void preorder(struct Node* root) {
    if (root == NULL) return;
    printf("%c ", root->data);
    preorder(root->left);
    preorder(root->right);
}

// Inorder: Left → Root → Right
void inorder(struct Node* root) {
    if (root == NULL) return;
    inorder(root->left);
    printf("%c ", root->data);
    inorder(root->right);
}

// Postorder: Left → Right → Root
void postorder(struct Node* root) {
    if (root == NULL) return;
    postorder(root->left);
    postorder(root->right);
    printf("%c ", root->data);
}

// Create and connect nodes
int main() {
    struct Node* root = createNode('A');
    root->left = createNode('B');
    root->right = createNode('C');
    root->left->left = createNode('D');
    root->left->right = createNode('E');
    
    inorder(root);  // Output: D B E A C
    return 0;
}

Key Concepts

  • Base Case: root == NULL stops recursion when reaching null child.
  • Preorder: Root processed first. Use when order of parent matters.
  • Inorder: Root processed between children. For BST, gives sorted output.
  • Postorder: Root processed last. Use for cleanup/deletion operations.
  • Memory: Use malloc for allocation, free for deallocation.
  • Base Case: root is None stops recursion safely.
  • Class Definition: Node class stores data and child references.
  • Flexibility: Python's dynamic typing lets any data type be stored.
  • Readability: Python code is clean and mirrors algorithm logic directly.
  • Memory: Python handles garbage collection automatically.
  • Base Case: root == null stops recursion when reaching null child.
  • Constructor: Node(char val) initializes new node with data.
  • Type Safety: Strong typing ensures correct node structure.

  • Memory: Java's garbage collector handles memory deallocation.

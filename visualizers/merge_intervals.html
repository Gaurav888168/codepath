Merge Intervals Visualizer

Sort intervals by start, then scan left to right. If current interval overlaps the last merged interval, extend it; otherwise start a new merged block.

Theory

Core idea: sort by start time first. Maintain output list. For each interval [s,e], compare with last merged [ls,le]. If s <= le, merge: last.end = max(le,e). Else append new.

Problem Statement

Given intervals where intervals[i] = [start, end], merge all overlapping intervals and return non-overlapping intervals covering same range.

Example: [[1,3],[2,6],[8,10],[15,18]] => [[1,6],[8,10],[15,18]]

Approach

How It Works

Step 1: Sort all intervals by their start point. This puts overlapping intervals next to each other.
Step 2: Iterate through sorted intervals and maintain a merged output list.
At each interval [s, e], check:
• If list is empty or s > last_merged.end → NO OVERLAP → Add as new interval
• If s ≤ last_merged.end → OVERLAP → Extend last interval's end

Result: Single pass through sorted array gives clean non-overlapping intervals. Time: O(n log n) for sorting, Space: O(n) for output.

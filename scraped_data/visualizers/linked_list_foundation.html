Node Structure

A linked list node contains two parts: data (the value) and next (pointer to the next node). The last node's next pointer is NULL.

Theory

A linked list is a linear data structure where elements are stored in nodes, each pointing to the next node. Unlike arrays, linked lists don't require contiguous memory, allowing dynamic memory allocation and efficient insertions/deletions at any position.

  • Node Structure: Contains data and a pointer to the next node
  • Head Pointer: Points to the first node in the list
  • Dynamic Memory: Each node is allocated individually during runtime
  • Key Operations:
    • Insert at beginning O(1)
    • Insert at end O(n) or O(1) with tail pointer
    • Delete O(n)
    • Search/Traverse O(n)
  • Real-world Applications:
    • Undo/Redo functionality
    • Navigation in multimedia players
    • Hash table collision handling
    • Polynomial representation
    • Implementation of queues and stacks

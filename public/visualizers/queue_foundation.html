Queue Foundation

Visualize a queue as a linear sequence where new items enter at the rear and items leave from the front in FIFO order.

Theory

A queue is another essential data structure that follows the First-In-First-Out (FIFO) principle, where the first element added is the first one to be removed. Think of a queue at a checkout counter—the first person in line is the first to be served. Unlike stacks, queues are designed for scenarios where items need to be processed in the order they arrive, making them perfect for task scheduling, messaging systems, and breadth-first search algorithms.

  • FIFO Principle: First In, First Out - the first element added is the first to be removed
  • Operations: Enqueue (add to rear), Dequeue (remove from front), Peek (view front without removing)
  • Real-world Applications:
    • Print job queues in operating systems
    • Task scheduling in CPU processing
    • Customer service request handling
    • Breadth-first search algorithms

Problem Statement

A queue holds items in arrival order. Enqueue adds to the rear, dequeue removes from the front. Use the demo to add values and observe how the structure shifts in FIFO order.

36int dequeue(Queue* queue) {

38return INT_MIN;

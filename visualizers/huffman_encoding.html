Huffman Encoding Visualizer

Build optimal prefix-free binary codes using character frequencies. See merge steps, tree construction, and generated bit codes together.

Theory

  • Goal: Minimize total encoded length by assigning shorter codes to frequent characters.
  • Data Structure: Use a min-heap to repeatedly pick the two smallest frequencies.
  • Tree Rule: Left edge adds bit 0, right edge adds bit 1.
  • Property: Huffman codes are prefix-free, so decoding is unambiguous.
  • Optimality: Greedy merge of least frequent nodes gives optimal weighted path length.

Problem Statement

Given arrays chars and freq, where freq[i] is the frequency of chars[i], construct Huffman codes and return the code for each character.

Required Output: Prefix-free binary strings where higher-frequency characters generally get shorter codes.

Example 1:

Input: chars = [a,b,c,d,e,f], freq = [5,9,12,13,16,45]
Output (one valid set): f:0, c:100, d:101, a:1100, b:1101, e:111
Explanation: More frequent f gets shortest code.

Example 2:

Input: chars = [A,B,C,D], freq = [10,15,30,16]
Output (one valid set): C:0, D:10, A:110, B:111
Explanation: Codes may differ by tie-breaking but weighted cost stays minimal.

Constraints:

  • 1 <= chars.length <= 10^5
  • 1 <= freq[i] <= 10^9
  • All characters are distinct.

huffman_encoding.txt

1function buildHuffman(chars, freq):
2heap = minHeap of leaf nodes
3while heap.size > 1:
4left = heap.popMin()
5right = heap.popMin()
6parent = Node('$', left.freq + right.freq)
7parent.left = left, parent.right = right
8heap.push(parent)
9root = heap.popMin()
10dfs(root, "") to generate codes

huffman_encoding.c

1// Min-heap based Huffman in C (outline)
2struct Node { char ch; int freq; struct Node *left, *right; };
3while (heapSize > 1) {
4left = extractMin(heap); right = extractMin(heap);
5parent = newNode('$', left->freq + right->freq);
6parent->left = left; parent->right = right;
7insertMin(heap, parent);
8}
9printCodes(root, arr, top);

Explanation

Heap Operations: extractMin and insertMin maintain smallest frequencies at top.

Merge Step: Internal parent node frequency is sum of two children.

Code Generation: DFS accumulates 0/1 path bits from root to leaves.

huffman_encoding.py

1import heapq
2def huffman_codes(chars, freq):
3heap = [[f, [c, ""]] for c, f in zip(chars, freq)]
4heapq.heapify(heap)
5while len(heap) > 1:
6lo = heapq.heappop(heap); hi = heapq.heappop(heap)
7for p in lo[1:]: p[1] = "0" + p[1]
8for p in hi[1:]: p[1] = "1" + p[1]
9heapq.heappush(heap, [lo[0] + hi[0]] + lo[1:] + hi[1:])
10return sorted(heap[0][1:], key=lambda x: x[0])

Explanation

heapq: Python min-heap gives O(log n) push/pop.

Bit Prefixing: Left group gets 0 prefix, right gets 1 prefix per merge.

Output: Sorted character-code pairs for readability.
